# How we’re building this (beginner-friendly)

Writers don’t start with storyboards. Storyboards are for **directing/shot design** after a script exists (or for animation production). We write in this order:

| Step | What it is | Output |
|---|---|---|
| **1. Series bible** | Rules, season map, character jobs | `BIBLE.md` ✅ |
| **2. Episode beat sheet** | Ordered list of story beats (not dialogue) | `beats-*.md` |
| **3. Scene card list** | Sluglines + 2–3 lines each (who wants what) | optional mid step |
| **4. Script draft** | Screenplay format, versioned `v0.N` | never overwrite |
| **5. Revise** | Passes for dialogue, pace, theme | `v0.N+1` |
| **6. Storyboard** (later, optional) | Pictures of shots — only when shooting/animating |

**Beat sheet = our next muscle.** If beats are wrong, dialogue can’t save them.

### Dialogue pass later
First drafts will sound stiff. That’s normal. We lock *what happens* and *why*, then do a dedicated pass: shorter lines, Bob’s nerd rhythm, Landers’ quiet honesty, FAITH’s pastoral threat.

### Premiere shape (locked)
**Two-part premiere**, airable as a movie night:

- **1x01 *Corpsicle*** — living Bob → death → slow wake → Landers + FAITH tension  
- **1x02 *Window*** (working title) — training → roamers attack → global fuse → Heaven acceptance / launch  

Convention **cold-open callbacks** = series device (book-like chapter energy).
